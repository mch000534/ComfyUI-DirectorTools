# Scene nine-grid layout

依使用者修正「上下左右分別是北南西東」，固定上北、下南、左西、右東。四角以左上、右上、左下、右下對應使用者列出的全景建立視角、45 度、主要焦點區域中景、環境細節特寫；45 度採俯視斜角。

row-major 順序：建立視角、北、45 度、西、頂視平面圖、東、主要焦點中景、南、環境細節。每列提示詞直接指定格子位置。

中央使用正投影頂視平面圖，北朝上東朝右，室內顯示無天花板遮擋的地面佈局、室外顯示場地佈局。格子位置不是地圖方向標記；四邊視圖從同一基準攝影機朝指定方位，地標與物件相對位置必須對應平面圖。其餘八格使用透視；移除舊版「九格均透視」要求。
