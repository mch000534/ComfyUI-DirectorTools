# Asset Prompt aspect ratio

新增 aspect_ratio 常用長寬比選單，附加到 optional 最後，以保留舊工作流程 widget 位置及 API。Auto 預設：角色沿用原本提示詞，不指定比例；九宮格 1:1；Panorama 固定 2:1，隱藏選單並忽略保存的其他比例。角色與九宮格可選 1:1、16:9、9:16、4:3、3:4、3:2、2:3、2:1、21:9。

比例只加入 STRING 生成提示詞，不調整圖片或 latent 尺寸。九宮格比例指整張設定圖，等大 3×3 切分後每格比例相同，非正方形比例不保留 square / 正方形模板要求。模式切換保留選單值。生成流程尺寸需要另設相符寬高。

測試兩種語言、角色比例、九宮格的整張和單格比例、Auto 回退、Panorama 固定比例、無矛盾 square 要求、欄位顯示、保存載入與舊 API 相容性。升版 0.10.1，同步前端快取鍵與 README。
