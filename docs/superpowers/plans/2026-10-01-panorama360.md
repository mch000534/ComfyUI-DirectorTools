# Panorama360 Implementation Plan

**Goal:** Match spherical preview and IMAGE output, with seamless 360-degree horizontal navigation.

**Architecture:** Shared perspective-to-equirectangular contract; native WebGL2 viewer; PyTorch row-chunked sampler with periodic horizontal bilinear padding. Existing node/hooks remain and projection is appended for old-workflow compatibility.

**Tech Stack:** Browser WebGL2, JavaScript modules, existing PyTorch/NumPy/Pillow, unittest, Node test runner, development-only Playwright.
